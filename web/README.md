# FlowMini React control panel

Creative desktop-style UI that replaces the tkinter control panel look: quiet slate at rest, crimson only while the mic is live.

This shell is visual + interaction demo. It does not yet call `flow_mini.py`.

## Run

```powershell
cd web
npm install
npm run dev
```

Open http://localhost:5173

- Click the disc or press Ctrl+Alt+D for a demo take
- Ctrl+Alt+F arms VAD
- HUD auto-hides after 10 seconds unless the mic is open
